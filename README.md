# Pfotenalltag – Hundetraining für jeden Tag

Kleine, verständliche Übungen für Alltag, Grundgehorsam, Bindung, Gelassenheit, Körpergefühl und Beschäftigung – offline, ohne Konto, ohne Abo.

## Nutzung

- Im Browser öffnen: `https://<benutzername>.github.io/<repository>/`
- Als App installieren:
  - Android/Chrome: Menü → „App installieren“
  - iPhone/Safari: Teilen → „Zum Home-Bildschirm“
- Nach dem ersten Öffnen startet Pfotenalltag auch ohne Internet.

## Datenschutz

Alle Eingaben – Hundeprofil, Trainingsverlauf, Tagebuch und Fotos – bleiben ausschließlich auf dem jeweiligen Gerät. Es gibt keine Server, kein Konto und kein Tracking.

## Update auf eine neue Version

1. `index.html` ersetzen.
2. In `sw.js` den Wert `CACHE_VERSION` erhöhen.
